# Event Attendance (QR code)

Students register → receive a QR code → staff scan it at the event → attendance is recorded in Google Sheets.

```
Google Form ──► Google Sheet ──► Apps Script
                (responses)      • gives each student a random token
                                 • emails their QR code (queued if over daily email limit)
                                 • "Get my QR code" page (web app)

Event day:
scanner/index.html (phone camera) ──POST──► Apps Script web app ──► "Attendance" tab
```

## Folder layout

| Path | What it is |
|---|---|
| `apps-script/Code.gs` | All server logic (tokens, email, check-in) |
| `apps-script/Lookup.html` | "Get my QR code" page for students |
| `apps-script/appsscript.json` | Apps Script settings (time zone, web app access) |
| `scanner/index.html` | Staff scanning page, hosted on GitHub Pages |

## Setup (about 20 minutes)

### 1. Create the Google Form
1. Go to forms.google.com → **Blank form**.
2. **Settings → Responses → Collect email addresses → Verified** (or "Responder input").
3. Add questions — titles must match `CONFIG` in `Code.gs`:
   - `Full Name` (short answer, required)
   - `Student ID` (short answer, required)
   - anything else you need
4. **Responses tab → Link to Sheets → Create a new spreadsheet.**

### 2. Add the script to the Sheet
1. Open the linked spreadsheet → **Extensions → Apps Script**.
2. Replace the contents of `Code.gs` with `apps-script/Code.gs` from this repo.
3. Click **+ → HTML**, name it `Lookup`, paste `apps-script/Lookup.html`.
4. **Project Settings (gear) → tick "Show appsscript.json"**, then paste `apps-script/appsscript.json`.
5. Edit the `CONFIG` block at the top of `Code.gs` (event name, details, column names).

### 3. Run setup (once)
1. In the editor, choose `setStaffPin` from the function dropdown. **Change the PIN in the code first**, then **Run**. Approve the permissions prompt (on "Google hasn't verified this app": Advanced → Go to project).
2. Choose `setup` → **Run**. This adds the `Token` / `QR Email Status` columns, the `Attendance` tab, and the triggers.

### 4. Deploy the web app
1. **Deploy → New deployment → type: Web app**.
2. Execute as: **Me**. Who has access: **Anyone**.
3. Copy the **Web app URL** (ends with `/exec`).
   - Give this URL to students as the "Get my QR code" page (e.g. put it in the form's confirmation message).
   - Staff enter it in the scanner's Settings.
   - After you change the code, use **Deploy → Manage deployments → Edit → New version** so the URL stays the same.

### 5. Host the scanner on GitHub Pages
1. In this GitHub repo: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
2. Scanner URL: `https://<your-username>.github.io/event-attendance/scanner/`
3. GitHub Pages is free only for **public** repos. That's fine here: the repo holds no student data or secrets (the URL and PIN are typed into the scanner on each phone).

### 6. Test
1. Submit the form yourself → check the email arrives with a QR code.
2. Open the scanner on your phone → Settings → paste the web app URL + PIN → scan the QR.
3. You should see a green "✓ Checked in" and a new row in the `Attendance` tab. Scan again → orange "Already checked in".

## Email limits

| Account | Approx. daily limit |
|---|---|
| Personal Gmail | 100 recipients/day |
| Google Workspace (school) | 1,500/day |

Over the limit, rows are marked `PENDING` and the hourly `sendPending` trigger sends them once quota resets. Students can always get their code from the **web app URL** without email. For ~200 students on a personal account: open registration at least 2–3 days before the event.

## Event day tips
- Open the scanner on 2+ phones; all write to the same Sheet safely.
- Turn up screen brightness on students' phones; keep a manual check-in by Student ID for forgotten phones.
- Export: in the Sheet, **File → Download → CSV/Excel** from the `Attendance` tab.

## Privacy notes
- The QR contains only a random token, not personal data.
- QR images are generated by `api.qrserver.com`, which sees only the token.
- Only staff with the PIN can record attendance.
